# Gestão 360

Gestão 360 — Gestão de Empresas de Engenharia Civil.

Aplicativo desktop para Windows, com arquitetura preparada para evolução para sincronização em nuvem.

## Módulos
- Dashboard
- Empresas
- Licitações
- Contratos
- Obras
- Diário 360
- Medições
- Documentos
- Obrigações e Alertas
- Financeiro
- Relatórios
- Configurações

## Arquitetura inicial
- Tauri 2
- React
- TypeScript
- SQLite local
- GitHub Actions para geração do instalador Windows

O projeto é construído de forma modular e local-first, preservando os requisitos funcionais definidos durante a evolução do Gestão 360.
